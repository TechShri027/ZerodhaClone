# 📈 Zerodha Clone – Full-Stack Stock Trading App

A fully functional **Zerodha-inspired stock trading platform** built using the MERN stack. This project simulates real-time trading operations and portfolio management features, offering users an intuitive and seamless trading experience.

---

## 🔧 Key Highlights

🔹 **Full-Stack Development**: Created from scratch using the **MERN** stack – combining MongoDB, Express.js, React.js, and Node.js to replicate a dynamic trading environment.

💻 **Frontend Excellence**: Developed a responsive UI using **ReactJS**, integrated with **Material-UI** components for sleek design, and **Chart.js** for real-time financial data visualization.

📊 **Data Management with MongoDB**: Designed a structured and scalable database schema to store and retrieve trading orders, portfolio holdings, and user profiles.

🔗 **Robust Backend Integration**: Built a RESTful backend with **NodeJS** and **ExpressJS**, integrating **CORS** for cross-origin requests and **body-parser** for efficient request handling.

⚙️ **Trading Functionality**: Implemented buy/sell order logic, dynamic margin calculation, and portfolio updates – mimicking core stock trading functionalities.

🚀 **Performance & Scalability**: Ensured optimized performance through clean code structure, API modularization, and production-grade deployment on **Render** and **Netlify**.

---

## 🛠️ Technologies Used

- **Frontend**: ReactJS, Material-UI, Chart.js, HTML, CSS  
- **Backend**: NodeJS, ExpressJS, MongoDB  
- **Middleware**: CORS, Body-Parser  
- **Deployment**: Netlify (Frontend + Dashboard), Render (Backend)
